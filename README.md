## Publish on GitHub
1. Sign in to GitHub and create a **new public repository**, for example `rohma-html-css-portfolio`.
2. Upload all 10 `.html` files, `style.css`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish. Copy the live URL shown in the Pages section.
6. Submit both the repository URL and live website URL.
